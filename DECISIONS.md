## Milestone 1 — skeleton + auth

- **Python version.** Docker image is `python:3.12-slim` as specified. The code avoids 3.12-only syntax so it also runs on the 3.11 used for local tests.
- **Config without pydantic-settings.** `config.py` reads `os.environ` directly into a frozen dataclass; keeps the dependency list to exactly FastAPI, uvicorn, httpx, yt-dlp, itsdangerous, pydantic. Startup refuses to run if `ACCESS_KEY`/`SECRET` are missing or still the `.env.example` placeholders.
- **No `python-multipart`.** `POST /login` parses `application/x-www-form-urlencoded` itself (`urllib.parse.parse_qs`) and also accepts JSON. One fewer dependency.
- **Session cookie.** `itsdangerous.TimestampSigner` over a constant payload, salt `media-saver-session`, verified with `max_age = 365 days`. `HttpOnly`, `SameSite=Lax`, `Secure` when `PUBLIC_BASE_URL` starts with `https://` (so plain-http local testing still works; production is always https).
- **Post-login redirect safety.** `next` is only honoured if it is a same-site path (`/…`, not `//…`, no backslashes); anything else falls back to `/`. `/`, `/share`, `/share-debug` redirect to `/login?next=<path+query>` with the full original share query preserved (tested).
- **Rate limiting.** Token bucket per client IP (30 tokens, refill over 300 s). Client IP is the first `X-Forwarded-For` hop because Caddy fronts the app; uvicorn runs with `--proxy-headers`. In-memory only; a restart resets it, which is fine for a personal tool.
- **Error contract.** One exception hierarchy (`errors.py`) shared by urlnorm, providers, and the API; a single handler renders `{error, message}` with the spec's status codes. Pydantic validation failures on `/v1/resolve` are also mapped to `unsupported_url` 400 so the page never sees FastAPI's default 422 shape (422 is reserved for `no_media`).
- **Download tokens.** `URLSafeTimedSerializer` (compressed JSON + signature). Payload keys are short (`u`,`p`,`h`,`f`,`m`) to keep URLs small; expiry is enforced by the serializer's timestamp with `max_age = 15 min`. Zip tokens use a different salt so a dl token can't be replayed as a zip token.
- **dl proxy.** Streams with httpx (256 KiB chunks, no buffering), forwards `Range`, passes through `Content-Length`, `Accept-Ranges`, `Content-Range`, `ETag`, `Last-Modified`; answers 206 only if upstream did. Filenames in `Content-Disposition` are ASCII-sanitised (`[A-Za-z0-9._-]`) since our own filenames are already in that alphabet. Upstream 4xx/5xx → 502, timeout → 504.
- **Zip.** Hand-rolled store-only streaming zip with data descriptors (no zip64) so nothing extra is pulled in; files must be < 4 GB, which media always is. Verified with `zipfile.testzip()` in tests.
- **Canonical URLs.** Twitter → `https://x.com/i/web/status/<id>` (author-independent). TikTok → `https://www.tiktok.com/@<author>/(video|photo)/<id>`, keeping the author segment when the shared link had it (avoids one redirect in yt-dlp); `@_` placeholder otherwise. Also accepts `fxtwitter/vxtwitter/fixupx` mirrors and `m.tiktok.com/v/<id>.html`.
- **Shortener expansion.** Only for `t.co`, `vm.tiktok.com`, `vt.tiktok.com`, `tiktok.com/t/…`; HEAD first, GET (`Range: bytes=0-0`) if HEAD is refused; max 5 hops, 10 s; query string of the final URL is dropped (TikTok appends tracking params). Non-shortener URLs are never fetched during normalisation.
- **Health.** `{ok, ytdlp_version, ffmpeg, version}` — `ffmpeg` added beyond the spec so the status page can flag a broken image.
- **Static serving.** FastAPI mounts `/static` too (so the app works stand-alone on :8000); in production Caddy serves `/static/*` from the same directory (bind-mounted read-only) and proxies everything else. `/manifest.webmanifest` and `/sw.js` are served by the app from the root path so the SW scope is `/`.
- **Service worker.** Single `VERSION` constant; `scripts/deploy.sh` stamps it with a timestamp+commit on every deploy. Cache-first for `/`, `/static/*`, manifest; everything under `/share`, `/login`, `/logout`, `/v1/` is left to the network (the SW does not call `respondWith`, so downloads go straight to Chrome's download manager).
- **Icons.** Generated by `scripts/gen_icons.py` with only the standard library (no Pillow): 192, 512, and a full-bleed 512 maskable variant. Committed as files.
- **`/share-debug`.** Dumps query params and environment, runs 3-file download tests at 0/400/1000 ms stagger against `/v1/debug/file/{n}` (auth-gated tiny text files with `Content-Disposition`), tests `window.close()`, simulates a share, and POSTs observations to `/v1/debug/log` so they land in the server log. Results go in §8.3/§8.4 below once run on a phone.
- **Compose.** App port 8000 is published on `127.0.0.1` only (for smoke tests and local use); Caddy is the public face. `SITE_ADDRESS` env selects the Caddy site; `localhost` gives a self-signed local cert.
- **Local verification environment.** The build sandbox has no Docker daemon and no ffmpeg; milestone 1 was verified with uvicorn + curl + pytest (63 tests). `docker compose up` itself must be run on a machine with Docker.
