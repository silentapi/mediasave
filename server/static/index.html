Setup

  1. Log in (done if you can read this).
  2. Install: Chrome menu ⋮ → Add to Home screen / Install app. The share-sheet entry only appears after installing.
  3. In Twitter/X or TikTok, tap Share → Media Saver.
  4. If Chrome asks to allow multiple downloads, allow it (remembered per site).

Files land in Download/ and show up in your gallery.
